Nakit Akışı Oyunu — Vercel Yükleme Rehberi

📋 Genel Bakış

  • ✅ Toplam süre: ~45 dakika
  • ✅ Gereken: Bilgisayar + internet + Gmail hesabı
  • ✅ Maliyet: Tamamen ücretsiz
  • ✅ Teknik bilgi: Hiç gerekmez
ADIM 1 — 5 dakika

GitHub Hesabı Aç

GitHub, dosyalarını sakladığın ücretsiz bir platform. Vercel, dosyaları buradan alır.

  1. github.com adresine git
  2. "Sign up" butonuna tıkla (sağ üst köşe)
  3. Email adresini gir → Şifre oluştur → Kullanıcı adı seç
  4. Email doğrulama kodunu gir
  5. Karşına çıkan seçeneklerde "Free" planı seç
✅ Başarı: Ana sayfanı görüyorsun — hesabın aktif.
ADIM 2 — 5 dakika

Yeni Repository (Klasör) Oluştur

Repository = GitHub'daki proje klasörün. Oyun dosyaları buraya gidecek.

  1. GitHub'da giriş yaptıktan sonra sağ üstteki "+" simgesine tıkla
  2. "New repository" seç
  3. Repository name: nakit-akisi-oyunu
  4. Public seçeneğini işaretle (Vercel ücretsiz için gerekli)
  5. "Add a README file" kutusunu işaretle
  6. Yeşil "Create repository" butonuna tıkla
✅ Başarı: github.com/KULLANICI_ADIN/nakit-akisi-oyunu sayfasını görüyorsun.
ADIM 3 — 5 dakika

oyun.html Dosyasını GitHub'a Yükle

Bu paketteki oyun.html dosyasını GitHub'daki klasörüne yükle.

  1. Repository sayfasında "Add file" butonuna tıkla
  2. "Upload files" seç
  3. oyun.html dosyasını sürükle-bırak veya "choose your files" ile seç
  4. Alttaki yeşil "Commit changes" butonuna tıkla
💡 oyun.html dosyası bu paketle birlikte geldi. Masaüstünde veya İndirilenler klasöründe bulabilirsin.
✅ Başarı: Repository'de oyun.html dosyasını görüyorsun.
ADIM 4 — 2 dakika

index.html Ekle (Önemli!)

Vercel, siteyi açmak için index.html arar. oyun.html'i index.html olarak da yüklemen gerekiyor.

  1. Bilgisayarında oyun.html dosyasını kopyala
  2. Kopyasının adını index.html olarak değiştir
  3. Aynı şekilde GitHub'a yükle (Add file → Upload files)
✅ Başarı: Repository'de hem oyun.html hem index.html var.
ADIM 5 — 10 dakika

Vercel Hesabı Aç ve Projeyi Yükle

Vercel, sitenin internette yayınlanacağı platform. Tamamen ücretsiz.

  1. vercel.com adresine git
  2. "Sign Up" → "Continue with GitHub" tıkla (Gmail ile GitHub açtıysan otomatik bağlanır)
  3. Ana sayfada "Add New Project" butonuna tıkla
  4. Sol tarafta GitHub repository'lerini görürsün. "nakit-akisi-oyunu" yanındaki "Import" butonuna tıkla
  5. Proje ayarlarını değiştirme, olduğu gibi bırak
  6. Mavi "Deploy" butonuna tıkla
  7. 2 dakika bekle — konfeti animasyonu çıkacak!
// Vercel sana şöyle bir link verir:
https://nakit-akisi-oyunu.vercel.app
// Bu link hemen çalışır, herkese açık.
✅ Başarı: Konfeti gördün, linke tıkladında oyun açılıyor!
ADIM 6 — 15 dakika (İsteğe bağlı)

Kendi Alan Adını Bağla

vercel.app uzantısı yerine kendi alan adını (nakit-akisi-oyunu.com.tr) bağlamak istersen:

  1. Vercel'de projenin sayfasına git → "Settings" → "Domains"
  2. Alan adını yaz ve "Add" tıkla
  3. Vercel sana iki DNS kaydı gösterir (A kaydı ve CNAME)
  4. Alan adını aldığın siteye git (Natro, İsimtescil vb.) → DNS Yönetimi
  5. Vercel'in gösterdiği kayıtları buraya ekle
  6. 24 saat içinde alan adın aktif olur
💡 Alan adın yoksa şimdilik vercel.app linki yeterli. İlk müşterileri bu linkle de kazanabilirsin.
ADIM 7 — Güncelleme Nasıl Yapılır?

Oyunu Güncellemek İstersen

Oyunda değişiklik yapmak istediğinde Vercel'e tekrar girmen gerekmez. Sadece GitHub'a yeni dosya yükle — Vercel otomatik günceller!

  1. Bilgisayarında oyun.html dosyasını Not Defteri ile aç ve değişikliği yap
  2. Kaydet
  3. GitHub'daki repository'ye git
  4. index.html üzerine tıkla → sağ üstteki kalem (✏️) simgesine tıkla → içeriği sil, yeni kodu yapıştır → "Commit changes"
  5. Vercel 1-2 dakika içinde otomatik günceller
✅ Bu kadar! Artık sitenin sahibisin.
